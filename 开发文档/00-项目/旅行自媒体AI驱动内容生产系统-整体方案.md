# 旅行自媒体 AI 驱动内容生产系统 — 整体方案

> **版本**: v3.0 | **日期**: 2026-05-24
> **状态**: 方案规划阶段（商业化方向）

---

## 一、系统概述

### 一句话定义

**面向传统企业老板和个体创业者的一站式 AI 自媒体运营系统**——用户只需"聊天式"提供自己和产品的信息，系统自动完成从定位、选题、视频制作、多平台发布、私域转化到数据迭代的全流程。

### 产品定位

从个人提效工具升级为**商业 SaaS 产品**。目标用户是不懂自媒体理论、不会剪辑软件、没时间研究算法的传统生意人。系统要让他们**像发朋友圈一样简单地运营自媒体账号**。

### 两大设计铁律

| 铁律 | 含义 | 具体表现 |
|:---|:---|:---|
| **零思考** | 不要让用户思考，傻瓜一看就会用 | 每一步都是 AI 主动提问/建议，用户只做选择题和确认；没有空白输入框，永远有默认选项；复杂概念全部可视化、实例化 |
| **AI 深度集成** | AI 不是辅助工具，而是系统的大脑 | AI 驱动每一个环节的决策；AI 主动发现问题并推送建议；用户只负责"提供真实信息"和"拍板"，其余全由 AI 完成；系统自动从结果中学习，越用越聪明 |

### 核心目标

**降低信任成本，加速转化。**

旅游是高价、低频、非标、决策重的消费。客户买的不是"线路"，而是"交给谁"。所有环节都服务于一件事：让潜在客户在出发前，就确信"这个人靠谱"。

### 目标平台

小红书（优先）> 抖音（同频共振）> 视频号（复用分发）

### 内容形态

以 **3D/2D 地图动画 + 口播** 为核心的 1-3 分钟短视频，辅以多平台派生版本（抖音快剪版、小红书图文版）。

## 二、贯穿始终的核心原则

### 第一层：产品铁律（不可妥协）

| 原则 | 含义 | 执行方式 |
|:---|:---|:---|
| **零思考** | 不要让用户思考 | AI 主动提问并给选项；没有空白输入框；每步有"下一步"引导 |
| **AI 深度集成** | AI 是系统大脑，不是工具 | AI 做所有分析和决策，用户只确认和选择 |

### 第二层：内容质量底线

| 原则 | 含义 | 执行方式 |
|:---|:---|:---|
| **"人味儿"不可替代** | 真实经历和情感表达是信任核心 | 口播占比默认 70%；AI 自动检测并标记"AI味过重"的文案 |
| **版权合规红线** | 素材只用免费可商用或 AI 生成；AI 内容主动标识 | 素材库自带授权标签；发布前自动检查合规项 |

### 第三层：运营策略

| 原则 | 含义 | 执行方式 |
|:---|:---|:---|
| **先跑通再自动化** | 内部先手动跑通全流程，验证后再自动化 | 分三阶段实施（手动 → 半自动 → 全自动） |
| **60 分就沉淀** | 任何效果达 60 分的操作，立即沉淀为 Skill | 6 步 Skill 化流程（见第八章） |

### "人味儿"自动检查（AI 在发布前自动执行）

系统自动扫描每条待发布的视频，对以下三点给出评分（红/黄/绿）：

1. 这条视频里，有没有一段话是用户自己真正想说的，而不只是 AI 分析出的"爆款话术"？
2. 观众看完后，会觉得"这人挺真诚"，还是"这人挺会做视频"？
3. 如果去掉动画和特效，这段话本身还站得住吗？

用户只需看到红/黄/绿灯并决定是否调整，不需要自己思考这些问题。

### AI 中枢三大核心

#### 1. 品牌记忆（记住"你是谁"）

AI 对每个用户维护一份持续更新的"品牌画像"，它是所有模块共享的上下文：

| 记忆内容 | 来源 | 如何更新 |
|:---|:---|:---|
| 人设定位（性格/风格/口头禅） | 首次 IP 访谈 + 后续每次交互 | 用户改口吻时自动学习新风格 |
| 目标客户画像 | CRM 实际客户数据 | 每成交一单，自动更新客户画像 |
| 什么内容有效 | 历史视频数据 | 自动关联高完播率/高转化视频的特征 |
| 什么话术有效 | 私聊转化数据 | 自动关联高转化话术的模式 |
| 行业/竞品认知 | 持续采集的竞品数据 | 自动更新行业趋势认知 |
| 用户的修改习惯 | 每次用户对 AI 产出的修改 | "用户总把'不可错过'改成'绝了'"→ 自动学习 |

**用户感知**：系统"越来越懂我"，生成的文案越来越像我自己写的。

#### 2. 策略引擎（跨模块自动协调）

策略引擎是 AI 中枢的"决策中心"，它打破模块壁垒，实现跨模块的自动协调：

| 策略场景 | 协调的模块 | 自动化行为 |
|:---|:---|:---|
| CRM 发现客户集中问某问题 | 模块5 → 模块2 | 自动将该问题推荐为明日视频选题 |
| 某条视频完播率异常高 | 模块6 → 模块2+3 | 自动提取该视频的"成功基因"（开头模式/节奏/钩子），应用到下一条 |
| 某条朋友圈互动特别高 | 模块6 → 模块5 | 自动分析原因，后续朋友圈优先使用类似风格 |
| 竞品出了爆款 | 模块1 → 模块2 | 自动采集 + 分析 + 推荐跟进选题 |
| 客户进入"犹豫"阶段 | 模块5 CRM → 模块5 私聊 | 自动推送促信任话术 + 推荐发送哪条已有视频 |
| 新热点出现 | 外部 → 模块2 | 自动判断热点与人设的匹配度，匹配度高则推送"紧急选题建议" |

**用户感知**：系统"主动帮我操心"，不是我去找事情做，而是事情自动找到我。

#### 3. 进化引擎（从结果中自动学习）

进化引擎是系统"可进化"的核心。它让系统越用越聪明，用户完全无感：

| 学习维度 | 学习机制 | 效果 |
|:---|:---|:---|
| **内容进化** | 对比每条视频的数据表现，自动识别"成功模式"和"失败模式" | 第 100 条视频的选题和脚本质量远高于第 1 条 |
| **话术进化** | 对比不同私聊话术的转化率，淘汰低效话术，复制高效话术 | 转化率随使用时间持续提升 |
| **风格进化** | 记录用户每次对 AI 产出的修改，提炼"用户偏好规则" | 文案风格越来越像用户本人 |
| **节奏进化** | 分析最佳发布时间、朋友圈发送时间、客户回复高峰时段 | 推送的时间建议越来越精准 |
| **Skill 自动升级** | 当某个 Skill 的效果持续低于预期，自动触发调优流程 | Skill 从"实验版"自动升级到"稳定版" |

**进化引擎的工作方式**：

```
[执行任务] → [采集结果数据] → [与历史数据对比] → [发现模式]
                                                         │
                     ┌───────────────────────────────────┘
                     ▼
              [模式有效？]
              │          │
           是 ▼       否 ▼
     [强化该模式]  [弱化/淘汰该模式]
              │          │
              └────┬─────┘
                   ▼
         [更新品牌记忆 + 更新 Skill]
                   │
                   ▼
         [下一次任务使用更新后的策略]
```

**用户感知**：不需要做任何事，系统就在变好。一个月后回头看，内容质量和转化率明显提升。

### 设计原则

- **AI 中枢驱动**：所有模块共享一个 AI 大脑，不是 6 个独立 AI，而是 1 个大脑的 6 只手
- **统一主干**：一个任务贯穿 6 个模块，数据自动流转，不需要手动搬运
- **可插拔模块**：每个模块可独立运行、独立升级，换工具不影响其他模块
- **自动进化**：系统从每次结果中自动学习，越用越聪明，用户无感
- **多租户架构**：每个用户独立的人设配置、素材库、数据空间，互不干扰
- **人设可导出**：用户的 IP 定位配置和品牌记忆是核心资产，支持导出和迁移

## 四、技术选型

| 编号 | 决策点 | 选型 | 理由 |
|:---|:---|:---|:---|
| 1 | 数据采集 | **MediaCrawler** 为主，TikOmni Skills 进阶引入 | 社区最活跃（35k+ Star），支持小红书/抖音/B站/微博 |
| 2 | 文案提取 | **ffmpeg + faster-whisper**（本地部署），备选 FunASR | 零成本、数据留本地、中文识别带时间戳 |
| 3 | AI 口播 | **ElevenLabs**（声音克隆）+ **edge-tts**（免费备选） | ElevenLabs 复现语调情绪；edge-tts 用于快速验证脚本 |
| 4 | 视频渲染 | **Remotion** | 唯一能用代码精确控制音画同步且与 CC 无缝集成的方案 |
| 5 | 视频号采集 | **初期手动录入** | 无成熟开源方案；手动观察反而能建立第一手感知 |
| 6 | 地图动画 | **短期：2D 地图 + Remotion 动画；中期：Three.js + OSM** | 自建 3D 工程量大，先用 2D 验证内容跑通 |
| 7 | 后端技术栈 | **Node.js + TypeScript** | 零切换成本（Remotion 本身是 Node 项目） |
| 8 | 系统形态 | **Web 应用**（浏览器访问，后期可扩展移动端） | 开发成本适中，一人即可全栈 |
| 9 | 数据存储 | **PostgreSQL** | JSON 支持强（存脚本结构、分析结果）；与 Dify 兼容 |
| 10 | 任务调度 | **事件驱动 + 定时轮询** | 模块完成自动触发下一个；监控数据定时采集 |
| 11 | 客户管理 | **内置 AI-CRM**（非外部 CRM 集成） | 轻量化、AI 自动填充、与内容系统深度打通 |
| 12 | AI 中枢 | **LLM + 向量数据库（品牌记忆）+ 规则引擎** | LLM 负责生成和理解；向量库存储品牌记忆和用户偏好；规则引擎负责跨模块协调和自动进化 |

## 五、六步闭环详解

### 闭环总览

```
[定位] → [对标分析与选题] → [素材准备与视频生成] → [发布与分发] → [私域转化] → [数据监控与迭代]
              │                                                      ↑              │
              │                ┌─────────────────────────────────────┘              │
              │                ▼                                                     │
              │         [公域引流 → 加微信]                                            │
              │                │                                                     │
              │                ▼                                                     │
              │    [朋友圈种草 → 私聊建信 → 群内筛选 → 转化下单]                        │
              │                                                                    │
              └──────────────────── [改进指令 → 新视频] ← 持续进化闭环 ────────────────┘
```

**公域打广度，私域打深度，数据打精度，AI 打一切。**

- 公域（小红书/抖音/视频号）：吸引注意力，把人引到微信
- 私域（朋友圈/微信群/私聊）：持续种草，建立信任，完成转化
- 数据：驱动两个域的内容持续优化
- AI 中枢：协调所有模块，自动学习进化

### 5.1 第一步：定位（回答"凭什么是我？"）

这一步的核心是完成四个层次的梳理：**自我画像 → 产品定位 → 人群画像 → 内容形式**。

#### 5.1.1 自我画像——挖掘"我是谁"的底色

这是所有步骤的起点。如果跳过这一步，后期会因"人设崩塌"或内容枯竭而崩溃。

**四层提问框架：**

| 层级 | 提问方向 | 示例问题 | 挖掘目的 |
|:---|:---|:---|:---|
| 第一层：事件 | 回忆具体的高光/至暗时刻 | "带团这几年，有没有哪次客人当场感动到哭？" | 找到最有故事性的素材 |
| 第二层：行为 | 在那个时刻，你做了什么？ | "当时你是怎么做的？别人遇到这种情况一般怎么做？" | 提取行动模式和独特方法论 |
| 第三层：感受 | 你为什么那么做？情绪是什么？ | "为什么你会先做那件事？当时心里在想什么？" | 找到价值观和情感驱动力 |
| 第四层：信念 | 这里面反映了你相信什么？ | "如果用一个原则总结你的做法，那是什么？" | 提炼 Slogan 和核心理念 |

**产出物**：个人标签（3-5 个关键词）、核心 Slogan、风格样稿（200 字以上）。

**AI 中枢的角色**：品牌记忆从这一步开始建立，后续所有模块共享这份画像。随着用户使用，画像会被持续更新（如用户总改某些词 → 自动更新语言风格）。

#### 5.1.2 产品定位——明确"我卖什么"

产品设计里的每个环节，都应体现自我画像中的价值观和专业能力。

**全链路拆解框架：**

| 环节 | 深挖问题 | 挖掘目的 |
|:---|:---|:---|
| 资源端 | 住宿/车辆/合作餐厅怎么选的？淘汰过哪些？有没有独家资源？ | 找到"独家供应链"——硬壁垒 |
| 设计端 | 路线为什么这样走？刻意放弃了哪些热门景点？增加了哪些隐藏点？ | 找到"设计哲学"——产品灵魂 |
| 服务端 | 路上会为客人做什么"分外之事"？有自己的品控清单吗？ | 找到"服务温度"——情感连接 |
| 市场端 | 客单价为什么定这个价？回头客和老带新比例是多少？ | 找到"定价权"和"口碑来源" |
| 竞争端 | 客人拿你和同行比最常问什么？你在哪个环节输给过竞争对手？ | 找到"真实竞争位置"和"认知盲区" |

**产出物**：核心产品 + USP（独特卖点）。

#### 5.1.3 人群定位——找到"为谁服务"

基于自我画像和产品定位，目标客户自然浮现：

- **人口属性**：年龄、城市、家庭状况
- **消费心理**：为什么选小包团而不是大巴团？
- **内容偏好**：喜欢干货攻略、情感故事还是硬核探险记录？

#### 5.1.4 内容形式——决定"怎么说"

这是前三者的自然交汇点。以"老X"为例：

- 经历丰富 + 说话直爽 + 产品主打专业独特 → **口播出镜** 是建立信任最快的路径
- 辅以 **3D 地图动画** 可视化独家路线，形成"人+技术"的信任壁垒
- 补充 **AI 实景口播**（首尾帧技术）作为"分身"工具，用于标准化信息输出

#### 5.1.5 IP 定位访谈助手（程序化）

将以上挖掘方法封装为一个 **AI 驱动的 IP 定位访谈助手**，通过结构化提问自动引导用户完成自我剖析。

**四个核心模块：**

| 模块 | 功能 | 核心提问逻辑 |
|:---|:---|:---|
| 个人故事挖掘 | 挖掘经历、能力和性格 | 高光时刻、至暗时刻、性格判断、兴趣热情 |
| 价值观提炼 | 找到驱动行动的内核（IP 的"魂"） | 追因、价值排序、批判思辨 |
| 产品全链路诊断 | 将专业优势结构化呈现 | 资源端、设计端、服务端、市场端、竞争端 |
| 交叉分析 | 整合前三模块，生成 IP 定位画布 | 交叉点发现、差异化提炼、人群对位 |

**最终产出**：一份结构化的「IP 定位画布」，包含个人标签、核心 Slogan、价值主张、独特卖点、表达风格、目标受众画像。

**关键难点**：程序必须能识别"浅回答"并追问到第四层（信念层），不能停留在表面信息。

### 5.2 第二步：对标分析与选题（回答"今天做什么？"）

#### 5.2.2 爆款分析框架

筛选出 3-5 条真正的爆款后，用以下视角拆解：

**视频"分镜与节奏"分析：**

- 信任建立方式：实地经历 / 专业解读 / 数据支持 / 独特审美
- 中间干货结构：总-分-总 / 清单体 / 时间线体 / 误区-纠正

**热点来源：**
- 各平台热搜榜（抖音/小红书/微博同城榜、旅游分类）
- 旅游行业媒体（环球旅讯、知名旅游博主）
- 官方发布（景区免票、新路开通、极端天气预警）
- 公共事件与情感话题（高考毕业旅行等）
- 自动化工具：新榜（跨平台热点聚合）、5118（SEO 需求图谱）

**三种结合方式：**

| 方式 | 逻辑 | 示例 |
|:---|:---|:---|
| 热点作"引子" | 热点事件 → 用户痛点 → 你的解决方案 | "#独库公路开通 冲上热搜，今年会不会又堵成'堵哭公路'？" |
| 热点作"佐证" | 热点观点 → 表达认同/反对 → 你的产品设计逻辑 | "最近'特种兵旅游'被官媒批评走马观花。深有同感。" |
| 热点作"解决方案" | 热点需求 → 给出替代方案 → 展示专业路线 | "高考结束了，第一次来新疆预算有限又想玩好……" |

**三个避免**：避免硬蹭、避免争议话题、避免延迟（24-48h 内跟进）。

**AI 中枢的角色**：策略引擎自动判断热点与人设匹配度，匹配度高则主动推送"紧急选题建议"，不需要用户自己去刷热搜。

#### 5.2.4 选题决策

**AI 中枢的角色**：品牌记忆 + CRM 客户洞察共同驱动选题。如果 CRM 发现最近 10 个客户都在问某个问题，策略引擎会自动提升该问题相关选题的推荐权重。

**产出物**：当日内容策略单。

### 5.3 第三步：素材准备与视频生成（回答"怎么做出来？"）

#### 5.3.1 从文案到"导演脚本"

**文案和脚本是两回事：**
- 文案 = "说什么"（纯文字口播稿，只解决信息层）
- 脚本 = "怎么说"（包含画面、声音、节奏、情绪的综合执行方案）

**"导演思维" = 在每一个段落回答四个问题：**

| 问题 | 维度 | 示例 |
|:---|:---|:---|
| 看什么？ | 视觉 | 3D 地图飞行动画？实拍空镜？出镜讲解？ |
| 听什么？ | 听觉 | 背景音乐什么情绪？加什么音效？ |
| 感觉什么？ | 节奏与情绪 | 快还是慢？镜头动还是静？好奇、震撼还是安心？ |
| 为什么？ | 目的 | 拉高期待？建立专业感？消除顾虑？引导转化？ |

#### 5.3.2 去AI味——脚本"人味儿"终审

**绝对禁止（即刻拉黑的词句）：**
- "总的来说"、"总而言之"、"此外"、"与此同时"、"不可错过"、"必打卡"
- 超过 25 个字的长句
- 一段话里对同一个东西用超过 2 种花名或代词

**强制执行的"人味儿"注入：**
- **观点黑即黑，白即白**：给主观、偏执的判断，不做"端水大师"
- **用身体感受说话**：不说"海拔 3200 米，含氧量低"，说"下车刚走两步，脚底下跟踩了棉花似的"
- **暴露"职业强迫症"**：偶尔跳出解说，指出只有从业者才在意的细节
- **加入临场细节**：把"这里的风景很美"改成"我带客人走到这里时，有个大姐当场就哭了"
- **分享决策逻辑**：不只说"我们选择住 A 酒店"，说出你决策时的考量
- **口语化替换**："因此"→"所以呢"、"于是"→"你看啊"

**去AI味三步法：**
1. **人设注入（事前）**：在指令开头详细描述语言风格，提供风格样稿
2. **指令约束（事中）**：强制执行禁止词表和风格规则
3. **审-改-读（事后）**：自己默读 → CC 朗读 → 给朋友看

**禁止词库**：做成可迭代的动态词库，每次审稿发现新的 AI 味表达，自动追加。

**AI 中枢的角色**：进化引擎自动记录用户每次对脚本的修改，提炼为"用户偏好规则"并更新品牌记忆。比如"用户总把'不可错过'改成'绝了'"→ 下次生成时自动用'绝了'。

#### 5.3.3 口播占比

| 视频类型 | 建议口播占比 | 策略说明 |
|:---|:---|:---|
| 知识干货型（痛点解答/线路拆解） | **≥70%** | 价值全在"讲解"里，人声是核心 |
| 情感/信任故事型（个人经历/客户故事） | **50%-70%** | 留更多空间给实景空镜和音乐渲染 |
| 爆款引流型（快剪/卡点/视觉奇观） | **30%-50%** | 口播为"金句式"点缀，但开头身份宣告和结尾转化引导不可少 |

默认值 70%，可配置。

#### 5.3.4 素材准备

| 素材类型 | 来源 | 成本 |
|:---|:---|:---|
| **3D/2D 地图动画** | CC + Remotion 代码生成 | 零成本 |
| **实景视频与图片** | Pexels / Pixabay（免费可商用）| 零成本 |
| | Mixkit / Videvo（高品质免费视频）| 零成本 |
| | 新疆图片库（本地化素材）| 部分免费 |
| | 光厂 VJshi（付费独家素材）| 单条十几元起 |
| **AI 生成专属素材** | 即梦AI / Midjourney | 按量计费 |
| **背景音乐与音效** | 平台官方曲库（可商用标签）/ Audionautix / FreePD | 免费 |

#### 5.3.5 AI 首尾帧技术（补充工具）

**定位**：素材补充工具，用于生成"分身"口播视频，**不替代真人出镜**。

**核心原理**：首尾帧法——用关键静态图片，AI 脑补出中间动态视频，拼接成完整 Vlog。

**四步流程**：
1. 生成原始底图（Nano Banana，提示词公式：构图+人物+动作+场景+氛围+质感）
2. 生成动作序列图（基于底图微调动作）
3. 首尾帧生成视频片段（VE 3.1）
4. 后期合成（背景+人物抠像+配音）

**合规提醒**：AI 生成的逼真人物口播视频，发布时**必须标注 AI 生成内容**。

#### 5.3.6 视频组装（多频共振）

CC 精确调度四个层面的元素：信息层（口播）、视觉层（地图动画）、情绪层（音乐与音效）、节奏层（剪辑与编排）。

#### 5.3.7 长视频拼接（1-3 分钟）

CC 用 Remotion 的 `<Sequence>` 组件自动拼接多个 15-30 秒片段，修改成本极低。

#### 5.3.8 一鱼多吃——多平台版本派生

| 版本 | 时长 | 调整规则 |
|:---|:---|:---|
| 主版（小红书） | 1-3 分钟 | 完整脚本、70% 口播、封面图文并茂 |
| 抖音版 | 30-60 秒 | 前 3 秒钩子强化、快节奏快剪、加热门 BGM |
| 视频号版 | 1-2 分钟 | 标题改利他型、结尾加社交互动引导 |
| 图文版（小红书） | — | 从口播文案自动生成图文攻略 |

### 5.5 第五步：私域转化（回答"怎么把流量变成客户？"）

> 公域解决"被看见"，私域解决"被信任"。旅游这种高客单价生意，**真正的钱是在私域里赚的**。

#### 系统边界原则

**个人微信没有开放 API，系统无法直接操作微信。** 明确分工：

| 系统（军师）负责 | 用户（将军）负责 |
|:---|:---|
| 生成朋友圈文案 + 配图建议 | 打开微信，复制发送 |
| 生成私聊回复话术 | 打开微信，复制发送 |
| 生成群运营内容 | 打开微信，复制发送 |
| 提醒跟进时机 | 打开微信，手动跟进 |
| 生成引流资料包（路书 PDF 等） | 手动发给客户 |
| 记录客户信息（语音/文字录入） | 简单说一句或打勾 |

**核心体验目标：用户打开系统看到"今天要做的事"全部准备好，复制粘贴到微信即可。**

#### 5.5.1 公域到私域的引流设计

| 触点位置 | 钩子设计 | 示例 |
|:---|:---|:---|
| 视频结尾口播 | 引导私信领资料 | "想要详细路书，私信我发'路书'两个字" |
| 评论区置顶 | 置顶引导评论 | "评论区扣 1，我私信你发北疆避坑指南" |
| 个人主页 | 微信号/企业微信二维码 | 统一引流入口 |
| 图文版（小红书） | 文末埋微信号 | "更多路线细节，来找我玩 → [微信号]" |

**AI 中枢的角色**：策略引擎根据每条视频内容，自动生成匹配的引流话术和资料包（PDF/图片），用户一键下载后手动发给客户。

#### 5.5.2 朋友圈内容运营

**朋友圈内容公式（3-2-1 节奏）：**

| 类型 | 每日数量 | 内容 | 目的 |
|:---|:---|:---|:---|
| **专业干货**（3 条） | 路线知识、避坑提醒、景区实况 | 建立专业信任 |
| **生活/人味**（2 条） | 踩线途中的见闻、与客人的故事 | 建立真实感 |
| **软性转化**（1 条） | 客户好评截图、团期预告 | 引导咨询 |

**系统能力（用户操作流程）：**

```
系统自动生成今日朋友圈 → 用户打开系统看到 6 条待发文案（含配图建议）
                                      → 点击"复制文案"
                                      → 切到微信粘贴发送
                                      → 回到系统点"已发送 ✅"
                                      → 系统记录发送时间，用于后续效果分析
```

**关键设计**：
- 每条朋友圈旁边一个**"复制"按钮**，一键复制文案到剪贴板
- 一个**"已发送"按钮**，用户点完后系统记录发送时间
- 系统根据发送时间 + 用户后续反馈的互动数据，分析最佳发布时间

#### 5.5.3 私聊转化话术

**客户旅程四阶段：**

```
[新加好友] → [初步了解] → [深度咨询] → [犹豫决策]
    │              │              │              │
    ▼              ▼              ▼              ▼
 破冰+建信    挖需求+给方案    证专业+消顾虑    推一把+促成交
```

**系统能力（用户操作流程）：**

```
用户收到客户微信消息
  → 打开系统，看到 AI 已识别客户阶段（或手动选择阶段）
  → 系统展示 2-3 条回复建议
  → 用户选择一条，点击"复制"
  → 切到微信粘贴发送
  → 回到系统点"已回复"，可选输入客户说的关键信息（语音/文字）
  → 系统更新客户状态，设置下次跟进提醒
```

**降低录入成本的设计**：
- **语音录入**：用户对着系统说"王总问了独库公路堵不堵，4个人，7月中旬"，AI 自动提取关键词填入 CRM
- **一键选择**：客户阶段用按钮选择（"新加好友"/"在聊"/"犹豫"/"成交"），不用打字
- **快捷标签**：预设标签按钮（"亲子"/"情侣"/"预算敏感"/"高品质"），点击即打

#### 5.5.4 微信群运营

| 场景 | 运营策略 | 系统输出 |
|:---|:---|:---|
| **意向客户群** | 日常发路线实况、天气、限时优惠 | 每日群内容模板，用户复制发送 |
| **已出行客户群** | 行前准备提醒、行中实况播报 | 行前/行中/行后各阶段群消息模板 |
| **老客复购群** | 新路线首发、淡季特价 | 促销话术 + 海报文案 |

#### 5.5.5 内置 AI-CRM（客户关系管理）

**设计原则：系统做不到自动采集微信数据，但可以用最低成本让用户完成信息录入。**

**客户信息卡片：**

| 字段 | 录入方式 | 用户操作成本 |
|:---|:---|:---|
| 昵称/来源 | 用户手动输入或语音 | 3 秒 |
| 引流来源 | 下拉选择（哪条视频带来的） | 1 秒 |
| 意向等级 | 三个按钮：🔥高 / 🟡中 / ⚪低 | 1 秒 |
| 出行意向 | 语音："4个人，7月，北疆" → AI 自动提取 | 5 秒 |
| 当前阶段 | 四个按钮：新加好友/在聊/犹豫/成交 | 1 秒 |
| 客户标签 | 预设标签按钮点击 | 2 秒 |
| 跟进记录 | 语音或文字 | 5 秒 |

**新增一个客户的总录入时间 < 30 秒。**

**客户旅程漏斗（用户手动推进，系统辅助提醒）：**

```
[公域曝光] → [加微信] → [初步咨询] → [深度沟通] → [犹豫对比]
→ [成交下单] → [出行中] → [出行后] → [复购/转介绍]
```

用户在系统中更新客户阶段后，系统自动推送对应的下一步建议。

**AI-CRM 核心能力：**

| 能力 | 说明 | 实现方式 |
|:---|:---|:---|
| 语音录入 | 用户说话，AI 提取关键信息填入 CRM | 语音识别 + NLP 提取 |
| 智能提醒 | 超过 N 天未跟进的客户，推送提醒 + 话术建议 | 定时检查 + 主动推送 |
| 跟进建议 | 根据客户阶段，推送"今天建议给这 3 个客户发消息" | 策略引擎 + CRM 阶段匹配 |
| 转化漏斗可视化 | 每个阶段客户数量、停留时间 | 自动统计 |
| 沉默客户预警 | 超过 30 天未互动的客户标红 | 自动检测 |
| **反哺公域内容** | 分析客户常问问题 → 推荐为视频选题 | AI 中枢策略引擎跨模块协调 |
| 资料包生成 | 一键生成路书 PDF、攻略图片 | 模板 + 客户需求自动匹配 |
| 转介绍追踪 | 记录来源链（A 推荐 B） | 用户手动录入"XX推荐的" |

**CRM 数据如何反哺系统（AI 中枢驱动）：**

```
用户语音说："今天 3 个客户都问了独库公路堵不堵"
    → AI 提取关键词："独库公路" "堵不堵" "3个客户"
    → 策略引擎判断：这是一个高频客户问题
    → 自动推荐为明日视频选题："做一条独库公路避堵攻略"
    → 用户看到推荐，一键确认
```

**CRM 不是自动化的，但它的价值在于：把用户零散的微信聊天经验，变成系统可用的数据，反哺给内容生产。**

#### 5.6.4 分析到改进——数据闭环核心

**三个动作，当天闭环：**

**动作一：提取"一个关键词结论"**

| 数据现象 | 关键词结论 |
|:---|:---|
| 完播率低，但前期点击高 | 开头钩子和内容不符 |
| 点赞多但评论少 | 内容有共鸣，但没留讨论口 |
| 播放量卡在 5000 | 互动率不够触发下一级流量池 |
| 播放互动都不错但没私信 | 信任没建到位，或转化钩子太弱 |

**动作二：把结论"翻译"成 CC 可执行指令**

| 数据问题 | 给 CC 的制作指令 |
|:---|:---|
| 前 3 秒跳出率高 | 新脚本开头换成痛点提问 + 全景画面 |
| 中间互动率骤降 | 每 15-18 秒强制切换视觉元素 |
| 评论区不活跃 | 脚本结尾追加引导提问 |
| 私信转化低 | 干货后插入出镜段，强化行动指令 |

**动作三：CC 按指令生成改进版视频**

**AI 中枢的角色**：进化引擎自动完成以上三步——自动提取结论、自动翻译成指令、自动应用到下一条视频。用户只需要看一眼"系统建议这样做，OK？"然后确认。

每周花 10 分钟写三条：
- 本周最大的意外发现
- 本周最大的判断失误
- 下周要测试的一个新假设

## 八、自动化流水线——一键出片模式

### 8.1 核心理念

系统不只是帮人一步步做视频，而是提供**一键触发**的自动化流水线。用户选择一种模式，系统自动跑完全流程，只在关键节点暂停请用户确认。

### 8.2 四种自动化模式

#### 模式一：爆款翻新流水线（一键翻新）

**触发方式**：用户看到一条爆款视频 → 粘贴链接 → 点"一键翻新"

```
[粘贴爆款链接]
    │
    ▼ 全自动
[下载视频] → [提取文案] → [AI 改写（注入品牌记忆+去AI味）]
    │
    ▼ 全自动
[生成导演脚本] → [自动匹配素材（地图动画+Pexels空镜+AI配音）]
    │
    ▼ 全自动
[Remotion 剪辑合成] → [生成多平台标题/标签] → [生成朋友圈文案]
    │
    ▼ 暂停，等用户确认
[用户预览视频] → ✅ 满意 → [一键发布到公域] + [复制朋友圈到微信]
                  ❌ 不满意 → [语音/文字提修改意见] → [AI 修改后重新渲染]
```

**时间**：从粘贴链接到视频预览约 5-10 分钟。

#### 模式二：每日自动出片（日更模式）

**触发方式**：每天定时自动触发，无需用户操作

```
[每天早上 8:00 自动执行]
    │
    ▼
[采集昨日爆款数据 + 今日热点] → [AI 筛选匹配选题]
    │
    ▼
[结合 CRM 客户洞察（最近客户常问什么）] → [确定今日选题]
    │
    ▼
[自动生成全链路内容：文案 → 脚本 → 素材 → 配音 → 剪辑]
    │
    ▼
[推送给用户："今日视频已准备好，请确认"]
    │
    ▼
[用户看一眼，OK 就发布] → 公域自动发布 + 朋友圈文案复制到微信
```

**时间**：用户每天只需 5 分钟（确认 + 复制朋友圈）。

#### 模式三：热点紧急出片（抢时效）

**触发方式**：策略引擎检测到高匹配度热点 → 主动推送

```
[策略引擎：发现"#独库公路开通#"热搜，与你的定位高度匹配]
    │
    ▼ 推送
🤖 AI 助手："发现热点！建议立刻跟进，我已准备好脚本，30 秒后自动开始生成视频。
    如需修改请现在告诉我，否则将自动执行。"
    │
    ▼ 用户无操作则自动继续
[全链路自动生成] → [优先渲染（跳过排队）] → [推送给用户确认发布]
```

**时间**：从热点检测到视频预览约 15 分钟。

#### 模式四：客户问题视频（CRM 驱动）

**触发方式**：CRM 检测到同一问题被多个客户频繁提及

```
[CRM：最近 5 个客户都问了"带小孩去新疆安全吗"]
    │
    ▼ 策略引擎自动判断
[这个问题适合做视频] → [自动选题："带娃去新疆，这几个问题你必须知道"]
    │
    ▼
[全链路自动生成] → [推送给用户确认]
```

### 8.3 各模式对比

| 模式 | 触发方式 | 用户参与 | 出片时间 | 适用场景 |
|:---|:---|:---|:---|:---|
| 爆款翻新 | 粘贴链接 + 点按钮 | 预览确认 + 复制朋友圈 | 5-10 分钟 | 日常日更 |
| 每日自动 | 定时触发 | 看 5 分钟 + 确认 | 全自动，早上出结果 | 稳定日更 |
| 热点紧急 | 系统主动推送 | 确认或修改 | 15 分钟 | 抢时效 |
| 客户问题 | CRM 自动检测 | 确认 | 全自动 | 精准内容 |

| 环节 | 自动化程度 | 技术方案 |
|:---|:---|:---|
| 爆款发现 | ✅ 全自动 | MediaCrawler 定时爬取 + AI 筛选 |

### 8.5 人工检查点（不可跳过）

即使全自动化，以下节点**必须**经人工确认：

## 八、Skill 化方法论

### 核心理念

将个人已验证的最佳实践，封装成 AI 可直接调用的标准化指令集合。从"提示词工程"进化到"技能工程"。

### 六步 Skill 沉淀流程

```
Step 1: 积累成功经验（手动做出 60 分以上的结果）
    ↓
Step 2: AI 提炼提示词（喂入成功案例，让 AI 分析结构和模式）
    ↓
Step 3: 测试与调试（用新提示词创作，找到"调整点"和"约束点"）
    ↓
Step 4: 封装为 Skill（稳定后的提示词 + 使用场景 + 输入输出格式）
    ↓
Step 5: 多任务验证迭代（至少跑通 3-5 次不同场景，标记为"稳定版"）
    ↓
Step 6: Skill 库持续进化（60 分就沉淀，持续积累）
```

### Skill 验证标准

- **实验版**：刚封装，未验证
- **验证版**：跑通 1-2 次
- **稳定版**：跑通 3-5 次不同场景
- **退役版**：发现基于错误经验，标记退役原因

### Skill 与系统模块的对应

| 控制台模块 | 可嵌入的 Skill | 说明 |
|:---|:---|:---|
| 模块2：选题策略 | 爆款文案生成 Skill | 根据热点和竞品分析，自动产出文案初稿 |
| 模块2：选题策略 | 热点筛选 Skill | 自动抓取当日热点并匹配选题方向 |
| 模块3：视频生成 | 分镜脚本 Skill | 将文案自动转化为导演脚本 |
| 模块3：视频生成 | 剪辑合成 Skill | 调用 Remotion 和素材库，自动剪辑成片 |
| 模块4：发布分发 | 多平台标题 Skill | 一条内容生成三套平台适配文案 |
| 模块5：私域转化 | 朋友圈内容生成 Skill | 从视频脚本自动派生朋友圈文案 |
| 模块5：私域转化 | 私聊话术 Skill | 根据客户阶段自动匹配话术 |
| 模块5：私域转化 | 群运营内容 Skill | 自动生成每日群内容 |
| 模块5：私域转化 | 客户意图识别 Skill | 自动分析聊天内容判断客户阶段和意向度 |
| 共享服务 | 去AI味审查 Skill | 自动扫描文案中的 AI 味表达 |

### Skill 自动进化（进化引擎驱动）

进化引擎持续监控每个 Skill 的实际效果：

- 某个 Skill 的产出持续获得高数据表现 → 自动标记为"高效 Skill"，优先调用
- 某个 Skill 的产出持续表现差 → 自动触发调优流程或标记退役
- 用户对 Skill 产出的修改模式 → 自动提炼为新规则追加到 Skill

## 十、分阶段实施路线图

### 阶段一：内部验证期（第 1-2 周）

**目标**：跑通第一条视频的全流程，验证内容可行。

| 任务 | 说明 | 时间 |
|:---|:---|:---|
| 完成自我画像梳理 | 用四层提问框架，写出个人画像 | 1 天 |
| 选定 3-5 个对标账号 | 小红书、抖音、视频号各找 | 1 天 |
| 手动分析 1 条爆款 | 拆解钩子、结构、转化方式 | 半天 |
| 写出第一条文案 | 用 CC 辅助 + 人工去 AI 味 | 半天 |
| 转化为导演脚本 | 用四问法标注视觉、听觉、节奏、目的 | 半天 |
| 准备素材 | Pexels/Pixabay 免费素材 + Remotion 地图动画 | 1 天 |
| 生成并发布视频 | CC + Remotion 出片，手动发布到小红书 | 1 天 |
| 监控数据并记录 | 发布后 1h/24h/72h 三个节点查看 | 持续 |

**验证指标**：第一条视频 72 小时播放量 > 500，至少收到 1 条真实评论。

### 阶段二：Skill 积累期（第 3-8 周）

**目标**：沉淀 3-5 个核心 Skill，建立稳定产出节奏。

| 任务 | 说明 |
|:---|:---|
| 日更 1 条视频 | 1 条/天起步，质量优先于数量 |
| 每条达到 60 分的流程都沉淀为 Skill | 重点：文案生成、分镜脚本、标题生成 |
| 建立飞书管理看板 | 跟踪每条视频从选题到数据复盘的全流程 |
| 每周复盘 + 更新爆款元素库 | 30 分钟周报 + 踩坑日志 |
| 引入 MediaCrawler 半自动化采集 | 减少手动复制粘贴 |

**验证指标**：连续 2 周稳定日更，3 个以上 Skill 达到稳定版。

### 阶段三：系统化运营期（第 9-12 周）

**目标**：系统稳定运行，开始产品化探索。

| 任务 | 说明 |
|:---|:---|
| 日更 2 条视频 | 流程成熟后加速 |
| 搭建 Dify 工作流 | 核心环节自动化 |
| 探索 AI 首尾帧技术 | 作为"分身"工具补充内容矩阵 |
| 一鱼多吃常规化 | 每条视频自动派生 3 个平台版本 |
| n8n 自动化监控 | 采集 → 存储 → AI 分析 → 优化建议 |
| **邀请 2-3 个种子用户内测** | 找传统行业老板，观察他们能否独立完成全流程 |

**验证指标**：种子用户能在 30 分钟内独立完成从选题到发布的全流程。

### 阶段四：MVP 上线期（第 13-20 周）

**目标**：上线最小可行产品，验证商业模型。

| 任务 | 说明 |
|:---|:---|
| AI 向导式 UI 开发 | 聊天式交互界面 + 视频预览 + 一键发布 |
| 多租户架构上线 | 用户注册、独立空间、数据隔离 |
| IP 访谈助手产品化 | 从技术模块变成用户的首次使用体验 |
| AI-CRM 上线 | 客户自动记录、自动提醒、话术推荐 |
| 计费系统上线 | 体验版（免费）+ 个人版 + 专业版 |
| 首批 10-20 个付费用户验证 | 验证定价和留存 |

**验证指标**：月活用户 > 20，付费转化率 > 10%，月留存率 > 60%。

### 阶段五：规模化增长期（第 21 周起）

**目标**：产品稳定后扩大用户规模。

| 任务 | 说明 |
|:---|:---|
| 企业版开发 | 多账号管理 + 团队协作 + API |
| 跨行业模板库 | 旅游行业跑通后，扩展到餐饮、教育、本地服务等 |
| 内容营销 | 用自己的系统做自己的营销视频（dogfooding） |
| 渠道合作 | 与自媒体培训机构、MCN 机构合作推广 |

**去AI味改写**：
> "我是老X，44岁，在新疆跑了十年。说话特点：短句多、爱打比方、爱用反问、直接吐槽。信条是'用专业帮人避坑'。请用这个风格改写下面的文案。禁止：'总的来说'、'不可错过'、超过25字的长句。强制：每段有主观判断、有身体感受、有职业细节。"

**数据复盘→改进指令**：
> "我昨天视频数据：[贴数据]。关键词结论：[你的判断]。明天要做《[标题]》，请在脚本中嵌入以下改进：[列出改进点]。"
